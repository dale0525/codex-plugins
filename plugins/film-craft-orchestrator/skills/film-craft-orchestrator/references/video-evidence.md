### P2：补充与小说/改编视角

`Brandon Sanderson BYU Writing Lectures`（小说结构/世界观/对白，类型偏科幻奇幻）、`Helping Writers Become Authors`（人物弧/scene-sequel）、`The Creative Penn`（作家与改编访谈）、BBC Writersroom、OpenLearn、[ASC](https://theasc.com/)、[BBC Academy](https://www.bbc.co.uk/academy)。它们补充小说或工程基础，不能替代影视实拍测试。

额外可检索：`The Screenwriting Life with Meg LeFauve`（主题和情感弧）、`Go Into The Story / Scott Myers`（scene-sequence 与练习）、`Writers Guild Foundation adaptation panel`、`BAFTA Guru adapting a novel`。优先按受访者姓名、片名和 `screenwriter interview` 搜索，不把营销片段当完整课程。

剧本对读优先制片方公开的 For Your Consideration PDF、WGA/官方获奖脚本；8FLiX、Daily Script、IMSDB、SimplyScripts 版本和授权状态不一，不要抓取或再分发整部剧本。

### 已验证样例（2026-07-23，Edge 登录会话）

本次研究不随 skill 分发完整字幕。早期样本使用 YouTube 页面内置 Transcript 面板；13 条深度样本使用授权会话取得的音频与本地 ASR，保留输入 hash，并由研究者完整阅读后只写入短释义和时间码。

- **LFTS / The Dark Knight**（`pFUKeD3FJm8`）：章节在 0:55、2:57、5:35 附近分别聚焦“攻击主角弱点”“迫使艰难选择”“与主角争夺同一目标”。可蒸馏为练习：为原创反派写三轮升级，每轮让主角的优势变成代价，并记录选择如何暴露价值观。证据类型是 `video_claim`（E4），不是“反派写作定律”。
- **LFTS / Gone Girl**（`CF3lFPW4E1o`）：章节在 0:49、2:32、4:22 附近分别讨论高效动作行、场景末行指向、subplot character 作为同一问题的另一种处理。练习：把一场戏的最后一句改成可见决定；删掉解释性动作，只保留能传达语气/节奏的短动作行。
- **StudioBinder / Dan Harmon Story Circle**（`-XGUVkOmPTA`）：Transcript 依次标出 You/Need/Go/Search/Find/Take/Return/Change；6:29 附近明确提出“change has to be made visual”。这些是该视频的教学模型（E4）。研究时的临时播放器截图 `work/yt_probe/story_circle_389.jpg`（约 389 秒，不随 skill 分发）能看到深海军蓝背景上的彩色圆环局部、编号节点 `8` 和紫色箭头，播放器叠加清晰显示 `6:29 / 8:56`；记录为 `frame_status: sampled`, `source: manual_player_screenshot`, `screen_overlay: true`, `evidence_level: E1`。它不能证明整个视频如何论证，也不能替代逐帧分析。
- **BAFTA / She Said Writer on Turning Novels into Scripts**（`pN7KIxUXPwo`）：在 Edge 授权会话下取得完整音频，以 `whisper.cpp small.en` 生成带时间码 ASR，并完整人工阅读。1:07–2:25 讲“提取事件/必要对白→尽快离源起稿→回源补漏”；3:49–4:07 讲极限压缩后按反馈恢复；9:09–10:47 讲用记者 POV、幸存者主体性、压缩重复联系和可见年龄筛选材料；11:35–12:26 讲主动排除施害者/侵害画面。这些是受访编剧的项目经验（E2），ASR 专名仍需人工字幕交叉核对。七个工程化程序见 `distilled-video-procedures.json`。
- **StudioBinder / How to Write Great Scenes**（`3TukzX6R57Y`）：完整音频经同一 ASR 流程并人工阅读。3:05–8:14 讨论目标/障碍、不同冲突来源、故事弧和失败风险；12:27–16:17 讨论人物/情节功能与转折四效应；16:25–24:38 讨论演员 blocking、摄影机 staging、权力转移和长镜头注意力。五个工程化程序见 `distilled-scene-procedures.json`。该视频为二手课程型解释（E4），不是场景写作定律。
- **Outstanding Screenplays / 20 Screenwriting Tips from Aaron Sorkin**（`mbHD6GQUgu0`）：英文原始音轨经本地 ASR 并完整人工阅读。5:53–7:00 讨论 intention、obstacle 与 tactics；12:18–13:40 讨论从结尾发现影片后重建第二稿；18:50–19:47 讨论出声朗读；20:14–20:53 再次用欲望、障碍和策略定义人物。四个工程化程序见 `distilled-sorkin-procedures.json`。视频由多段访谈剪辑而成，E2 只表示讲者是一手创作者，不消除剪辑省略上下文的风险。

把以上时间码当作复习入口，不把短引文或章节标签当作完整论证。需要更高可信度时，回到视频、官方剧本/访谈和自己的复拍/重剪实验。

本目录的结构化证据队列分布在五个知识库。2026-07-24 验证结果为 62 条唯一视频、45 条 `deep_distilled`、104 个唯一程序；其中定向补强库新增 8 条 deep、17 个程序，并诚实保留 2 条只有电影对白的 `claim_evidence_only` 片段。另有 Arrival 与 The Social Network 两条解释型 Script-to-Screen 来源同时具备公开剧本版本、完整 ASR、剧本页/成片抽样帧和 4 个对读程序；它们的静帧状态仍为 `partial`，动态、声音和剪辑因果主张不得升级为直接事实。旧版 chapter/candidate 和 access-failed 仍不计作可执行知识。读取时必须尊重各条 `distillation_status`，不能用总数掩盖证据等级。

4 条 Transcript 核验样本的短摘录/释义和转化动作见 `video-transcript-evidence.json`；它不包含完整字幕。

5 条代表视频的 21 帧独立视觉观察见 `video-frame-evidence.json`。它记录源视频/帧 hash、时间码、可见构图、人物位置、光色、画面标签和不可推断项；静帧不升级为摄影机运动或剪辑因果证据。

## 证据等级

```text
E1 画面/字幕/音频中可定位的直接观察（带时间码）
E2 创作者本人或制作人员一手访谈/授权剧本
E3 可复现实验或多个独立来源一致
E4 频道作者的解释、课程模型或评论
E5 未核验的自动字幕、ASR、OCR、缩略图或用户转述
```

E4/E5 可以生成练习假设，不能单独支撑高风险事实。对一手意图也保留“受访者回忆”标签。

## 采集顺序

只处理用户有权访问的公开内容或用户提供的本地文件；遵守 YouTube ToS、速率限制和版权。推荐先保存元数据，再按需要取得最小媒体：

```bash
# 临时 pixi 环境，避免系统级安装
pixi exec --with yt-dlp yt-dlp --dump-single-json --skip-download URL > metadata.json

# 公开字幕；先列轨道，英文/中文按需选择
pixi exec --with yt-dlp yt-dlp --list-subs URL
pixi exec --with yt-dlp yt-dlp --write-subs --write-auto-subs \
  --sub-langs 'en,zh-Hans,zh-CN' --sub-format vtt --skip-download \
  -o 'work/captions/%(id)s.%(ext)s' URL

# 在授权范围内仅下载音频或低分辨率视频；下载失败时停止并走回退
pixi exec --with yt-dlp --with ffmpeg yt-dlp -f 'worstaudio/worst' \
  -x --audio-format wav -o 'work/media/%(id)s.%(ext)s' URL
pixi exec --with yt-dlp --with ffmpeg yt-dlp -f 'worst[ext=mp4]/worst' \
  -o 'work/media/%(id)s.%(ext)s' URL
```

不要用签名 token、代理或第三方下载站绕过登录、验证码、付费墙、DRM、年龄限制或 429。记录命令、工具版本、检索时间和输入 hash；下载失败不应让 skill 编造转录。

### 浏览器回退

当命令行被 429、字幕轨道限制或缺少 JS runtime 阻断时，可在用户已经登录的 Edge/Chrome 中：

1. 直接打开 YouTube 视频，使用页面的 **Show transcript** 和章节，复制少量带时间码的片段到本地证据包。
2. 在用户有权保存的前提下，暂停播放器并截取关键帧；记录 URL、`t=秒数`、屏幕状态和 `frame_status`。
3. 若用户明确允许下载且 YouTube 页面本身提供正常下载/离线能力，使用该能力或将用户导出的本地文件交给 `frames`/ASR 脚本。

`9xbuddy.site` 等第三方下载站不是默认路径：把 YouTube URL 发送给第三方会暴露浏览行为，服务也可能绕过平台限制、注入广告或改变文件。只有在用户已确认其合法性、隐私风险和目标内容的处理权，并且没有绕过 DRM/验证码/年龄限制时才可由用户自行操作；skill 不自动提交账号、cookie、签名 URL 或私人视频。

## 字幕与 ASR

优先人工字幕。`youtube-transcript-api` 版本 API 会变化，先探测 `YouTubeTranscriptApi().fetch(video_id, languages=[...])`，捕获 `IpBlocked`, `TranscriptsDisabled`, `NoTranscriptFound`, `VideoUnavailable`。字幕不可得且用户有本地音频时：

```bash
ffmpeg -i input.mp4 -ac 1 -ar 16000 -c:a pcm_s16le audio.wav
whisper audio.wav --model small --output_format json --word_timestamps True
```

或使用 faster-whisper；记录语言、模型、版本和置信度。统一所有输入为 `{start_sec,end_sec,text,source,language,confidence}`，保留原始区间，不把翻译覆盖原文。

## 画面、OCR 与时间码

对用户提供/授权的本地视频：

```bash
ffprobe -v error -show_streams -show_format -of json input.mp4 > probe.json
ffmpeg -i input.mp4 -vf 'fps=1/10,scale=1280:-1' -q:v 2 frames/%06d.jpg
ffmpeg -i input.mp4 -vf "select='gt(scene,0.35)',showinfo" -vsync vfr frames/scene-%06d.jpg 2> scene.log
tesseract frame.jpg stdout -l eng+chi_sim tsv > frame.tsv
```

用 `-copyts -vsync 0` 保留可变帧率时间戳；场景变化前后加密采样 5–10 秒。将帧映射到最近字幕/ASR 区间，URL 参考可写为 `https://youtu.be/VIDEO_ID?t=SECONDS`。缩略图只能记录可见文字、主体、构图和色彩，状态写 `thumbnail_only`，不能推断剪辑、运动、音频或剧情因果。

## 蒸馏 schema

```json
{
  "video": {
    "id": "pFUKeD3FJm8",
    "url": "https://www.youtube.com/watch?v=pFUKeD3FJm8",
    "title": "The Dark Knight — Creating the Ultimate Antagonist",
    "channel": "Lessons from the Screenplay",
    "retrieved_at": "2026-07-23T00:00:00+08:00",
    "duration_sec": 660,
    "license": "public-page; verify before redistribution"
  },
  "artifacts": {
    "captions_vtt": null,
    "asr_json": null,
    "frames_dir": "frames/",
    "frame_status": "thumbnail_only|sampled|not_available",
    "tool_versions": {}
  },
  "segments": [
    {
      "id": "seg-001",
      "start_sec": 42.1,
      "end_sec": 58.4,
      "text": "短的转化性摘录或摘要",
      "source": "caption|asr",
      "language": "en",
      "confidence": 0.92,
      "frame_refs": []
    }
  ],
  "claims": [
    {
      "id": "claim-001",
      "statement": "视频把反派的有效性归因于与主角价值观的镜像冲突",
      "kind": "video_claim|fact|interpretation|experiment",
      "segment_ids": ["seg-001"],
      "quote": "短引文，避免连续长段",
      "evidence_level": "E4",
      "evidence_refs": ["https://youtu.be/pFUKeD3FJm8?t=42"],
      "confidence": "medium",
      "uncertainty_flags": ["author_interpretation"]
    }
  ],
  "provenance": {"commands": [], "inputs": [], "hashes": {}},
  "verification": {"status": "unverified", "sources": []}
}
```

蒸馏规则：按时间排序、规范化后去重；重叠段合并但保留原始时间码；相似观点可聚类，不能抹去限定词、数字、否定或冲突。每条技能句都必须能回到 `claim → segment → timestamp`。只有再补齐 `applicability`, `inputs`, `steps(action+check)`, `outputs`, `failure_signals`, `acceptance_tests(pass_criteria)`, `worked_example` 才能标 `deep_distilled`；缺任一项必须降级。

## 失败回退

| 失败 | 回退 | 标记 |
| --- | --- | --- |
| YouTube 429/IP block | 等待并降低速率；由用户在本地导出字幕/视频；只做元数据 | `caption_unavailable` |
| 无人工字幕 | 自动字幕→本地 ASR；人工抽查每 20 段一段 | `auto_caption` / `asr` |
| 无音频权限 | 只做用户提供的字幕、截图和描述 | `text_only` |
| VTT/SRT 解析错误 | 转成统一区间，保留原文件和错误日志 | `parse_repaired` |
| OCR 模糊 | 提高分辨率/去噪/换引擎/人工核对 | `ocr_unclear` |
| 时间轴漂移 | 用片头同步点或音频对齐，记录校正 | `timeline_adjusted` |
| 视频已下架 | 保存标题、频道、访问日期和替代官方来源 | `unavailable` |

## 版权与隐私

输出应是转化性摘要、少量短引文、练习和可回溯链接，不能提供完整字幕、连续长转录、完整剧本或可替代原片的镜头序列。只保留完成任务所需的本地媒体，任务结束后删除或由用户自行归档。OCR/ASR 可能捕获姓名、邮箱、车牌、住址等 PII；在交付物中脱敏。视频中的专业建议不自动适用于用户片场；安全、医疗、法律和劳动问题转交合资格专业人员。
