# Web Novel Progression

## 共享知识

共享根是 `../web-novel-craft/`。每次创作先读 `../web-novel-craft/references/narrative-effect-contract.md`，再读 `../web-novel-craft/references/progression.md`；需要续写时只把已经进入正文的规则、成本和能力状态写入 `../web-novel-craft/references/story-bible.md` 所述轻量笔记。

## 工作流

1. 选择体现读者契约的成长轨，不限于战力。
2. 定义当前证据、下一阈值、获得规则、成本、反制、失败和世界响应。
3. 对 LitRPG 建规则台账：单位、阈值、获取、消耗、冷却、叠加、例外、信息权限。
4. 通过行动与后果介绍基本规则，再依赖复杂例外。
5. 让奖励回收承诺并改变策略、责任、暴露或未来压力。
6. 压缩无选择的 grind，展开会揭示规则、关系、风险或策略的训练。
7. 每个篇章边界审计 power creep、规则例外和旧能力的意义。

## 失败信号

- 数字上涨但可做的事没变；
- 奖励与努力/选择无关；
- 新规则只在解决危机时出现；
- 只能靠更高数值敌人维持紧张；
- 失败马上复原且无代价；
- 角色看不见也无法操作所谓游戏层；
- 统计说明压过欲望、选择与情感意义。

## 交付

交付成长轨、规则台账、奖励安排、成本/反制/失败、敌对响应、信息引入顺序和力量膨胀审计。

## 完成门

- 每个成长节点都写明改变了哪些可用选项、代价、反制和世界响应。
- LitRPG 规则的单位、阈值、获取、消耗、冷却、叠加和信息权限可逐项核对。
- 至少用一个失败或反制场景证明新能力不会只靠数字上涨维持紧张。
- 检查通过后停止继续堆数值；通用结构或局部表达转对应分技能。
