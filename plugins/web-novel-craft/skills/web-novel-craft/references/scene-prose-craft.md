# 中文网文场景与文体总流程

场景文体不能修复缺失的目标、选择和因果。先冻结场景功能，再处理叙述距离、展开密度、动作、感官、情绪、对白和句群。

## 场景合同

记录 POV、时间、地点、入口状态、即时欲望、阻力、信息权限、主体验、类型功能、出口变化和下一压力。低选择、重复过程与过渡可概述；冲突、抉择、发现和不可逆变化通常展开。`YAKcbvioxFk` 59–83、1313–1524 秒与 `BV1DyKp6AEVN` 8–49、743–767 秒共同支持 show/tell、概述/戏剧的功能分配，不能机械执行“全都 show”。

## 写作顺序

1. 先用 3–4 句概述固定时间和因果，再选择关键瞬间写戏剧版。
2. 选择叙述距离，列 POV 可感知输入和已知事实。
3. 把关键变化写成“外部刺激—身体/注意—人物解释—可见行动—后果”。
4. 环境每 2–3 句通过移动、受阻、触碰或选择进入，不列静态物品清单。
5. 对白从信息或关系转折切入，每轮改变信息、策略、关系或行动。
6. 动作/情绪高潮用回合表或选择因果图，公布真实结果和代价。
7. 句法二审检查主语、动词、施事者、关系词、信息焦点和移动端断行。

## 结构变化与体验证明

强项负责结构完整，弱项负责体验真实。每个重大选择、回收或不可逆状态变化，应在合适的余波窗口留下至少一种人物可感知的证据；普通推进节点不机械配置身体症状或象征。删除结构变化后，体验细节不能只剩装饰；删除体验证据后，读者应明显感觉代价没有真正落到人物身上。

余波场景仍要有当下目标。根据代价选择身体/感知、注意/解释、物件/空间、语言/沉默、关系距离、日常仪式中的两三种相关通道，不必全部使用。使用：

```text
相同或相似的日常刺激
-> 改变后的注意或解释
-> 可见的微小行动
-> 当下任务、信息或关系发生轻微偏移
```

身体反应必须对应具体经历；不要默认使用发抖、噩梦、失眠、饮酒或照镜子。反复出现的余响要改变触发、意义、应对或他人理解，不能复制同一症状。不要为了证明代价新增原事件无法支持的创伤。完整微观摩擦卡见 `choice-cost-experience.md`。

## 总验收

盲读者应在两句内指出 POV 和说话人，能复述空间、时间、目标、胜负、情绪动机及状态变化。重大余波还应让读者从刺激、注意、行动或关系偏移中感到代价仍在，而不依赖作者宣布“留下阴影”。若读者只记得形容词、招式名或“很虐”，却说不出角色做了什么、为何如此和付出什么，场景未通过。

英语写作课只迁移功能，不照搬时态、分词和 he-says cadence；语文句法课只证明结构操作，不证明点击、留存或商业效果。所有效果主张须由目标读者盲测或项目 A/B 数据验证。
