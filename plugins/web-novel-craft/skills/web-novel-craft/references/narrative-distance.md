# 叙述距离、自由间接引语与概述

## 权限先于风格

场景开头冻结 POV、地点、时间、可见/可听输入和当时已知事实。限知叙述不能无信号进入他人内心；全知、规则公告和作者性旁白可以拉远，但要遵守项目自己的 voice contract。

## 识别与验证

把现场信息标成感知、记忆、推断或已验证事实。人物身份必须先有可识别刺激，例如称呼、音色、动作习惯或可见特征，再允许 POV 人物认出；不能因为作者知道门后是谁，就让尚未获得线索的人物先报出名字。界面只证明界面显示的状态：看见拨号页不等于电话已经拨通，看见申请入口不等于申请成功。意识断续、隔门听不清或只听见一方说辞时，只能写人物当时能够形成的推测；离开、说服、完成等结果要等脚步、回音、回执、实际操作或其他足够证据出现后再确认。

## 距离刻度

- 远：跨时段概述、制度背景、群体变化；
- 中：可见动作、空间与可核验判断；
- 近：身体反应、注意偏向、人物词汇和即时联想；
- 内：明确思想、记忆和自我解释。

每次拉近或拉远标注目的：信息压缩、情绪放大、反讽、转场或读者定位。无目的漂移会造成串脑和作者替人物解释。

## 自由间接引语

让人物的词汇、价值判断和生活比喻进入第三人称，不必连续使用“他想/她觉得”。同一事件写直接、间接、自由间接三版；主体不清时恢复称谓、动作锚点或明确心理句。人物误判旁边保留外部可验证线索，后文兑现或修正。

`Yh5wZVSW89s` 90–118、520–585、644–668、891–1000、1109–1168 秒支持这些英语文学讲解。中文没有完全相同的时态和代词标记，应靠语气、称谓、词汇与段落定位迁移功能。

## 概述与戏剧

概述负责跨度、重复、低选择过程和主题抽象；戏剧负责冲突、发现、抉择和不可逆变化。关键瞬间按动作顺序同步展开，前后用日期、季节或事件锚点压缩。`BV1DyKp6AEVN` 8–254、303–547 秒提供中文概述/戏剧模型。

## 验收

- 任一心理判断可追溯到 POV 的感知、记忆或信念；
- 任一确定性识别和结果判断都有先行刺激或验证动作，推断没有伪装成事实；
- 多 POV 切换在两句内可定位；
- 概述未提前泄露悬疑答案，戏剧未把机械过程无限展开；
- 不可靠判断有可回收的外部证据；
- 叙述距离变化服务场景功能，而非模仿某位在世作者。
