# 轻量故事圣经

故事圣经只为写作记忆服务。用户已有自己的笔记格式时沿用；没有时只记录当前任务真正需要的内容，不建立项目管理系统。

## 最小内容

### 故事

- 一句话前提与目标读者体验；
- 主角现在想要什么、如何行动、失败会失去什么；
- 反复产生新问题的故事发动机；
- 当前主线、主要开放问题和结尾方向。

### 人物

- 欲望、策略、知识边界、关系和声音；
- 已发生的关键选择及其代价；
- 当前伤势、身份、物品或能力状态；
- 只有该人物会注意、说出或回避的内容。

### 世界与规则

- 已在正文成立的规则、成本、例外和读者已知范围；
- 地点关系、旅行时间和影响行动的环境条件；
- 派系目标、资源和相互关系；
- 仍是作者设想而未进入正文的内容单独标记。

### 承诺与连续性

- 已设置、正在推进和需要回收的伏笔/关系/谜题；
- 当前时间、地点、知识、伤势、物品、金钱和能力限制；
- 最近一章改变了什么，以及下一步因果压力。

## 使用方式

续写前快速核对相关条目；写完后只补充正文真正建立的新事实。发生冲突时，以用户确认和已写正文为准，指出矛盾并提供修复选择，不静默重写历史。笔记可以是自然语言、表格或用户已有文件，不要求稳定 ID、版本哈希、提交记录或自动化脚本。
