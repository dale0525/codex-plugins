# Romance 与关系弧

## 关系状态

```yaml
romance_arc:
  contract: romance|romantic_subplot
  ending: HEA|HFN|approved-variation
  partners:
    - character_id: char-id
      independent_goal: observable objective
      fear: what intimacy risks
      misbelief: belief driving wrong choices
      boundary: what must not be crossed
  beats:
    - stage: meet|interest|doubt|fall|retreat|choice|commitment
      action: observable behavior
      external_plot_link: event-id
      trust_before: proposed state
      trust_after: changed state
      cost_or_consequence: ''
      book_id: volume-id
```

## 程序

1. 区分以 romance 为主和仅含感情支线；主类型先确认结局承诺。
2. 分别写双方的独立目标、恐惧、误信、边界和关系外行动，不把一方降为奖品。
3. 用 meet→interest→doubt→fall→retreat→choice/commitment 作路线图，不把它当固定章节表。
4. 每次靠近或退后都必须由新行动或新信息造成，并留下不可逆后果；同一误会只准出现一次，除非后果和双方策略都升级。
5. 把外部危机、案件或成长节点连接到关系选择。高潮最好同时考验外部目标与信任缺口。
6. 多卷关系弧为每卷设置局部阶段满足；最终兑现已声明的 HEA/HFN 或经用户批准的变体。

## 验收与反例

- 每个阶段都有行为证据，双方目标都能独立复述。
- 删除亲吻、发糖和身体吸引后，仍能看见信任、承诺、边界或共同计划的变化。
- Slow burn 的等待产生 yearning、风险或认识更新，而不是把一次误会换措辞重复。
- 反例：案件独立解决，结尾突然宣布相爱；或一方永远只对另一方的行动作反应。
