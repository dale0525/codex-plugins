# 叙事效果合同

这是一份适用于网络/连载小说构思、写作、续写、改写、修订和评价的紧凑合同。它不是新的评分大清单，而是每次创作都要先对齐的一条因果链：

`读者承诺 → 人物发动机 → 压力/选项 → 选择/责任 → 后果/体验 → 文本实现`

## 六个相连的问题

1. **读者承诺**：这段要兑现哪一种题材、关系、谜题、升级或情绪体验？读者现在应能期待什么可见进展？
2. **人物发动机**：谁此刻想要什么，为什么只能用这个人物特有的策略？阻力和失败代价是什么？不要让事件替人物行动。
3. **压力/选项**：什么压力正在收紧？人物实际有哪些选项、限制和失去的选项？当本单元承载重要选择或状态变化时，至少一个选择应改变后续状态，而不是只改变场面声量。
4. **选择/责任**：人物知道或能感知哪些关键事实，如何在正当但不能同时满足的要求之间取舍？选择必须属于人物；解释动机不等于替人物免责。
5. **后果/体验**：结果要能从既有选择、规则和他人自主反应回溯，并以身体/注意、物件/空间、语言、关系距离或日常行动中的具体摩擦让人物经历它。
6. **文本实现**：用合适的 POV、动作、感官、对白、叙述距离、节奏和概述比例把前五项变成读者可感知的句段；文字润色不能替代上游缺失的选择或后果。

## 三道护栏

### 道德净化

不要为了让角色“配得上”读者喜爱而抹平伤害、动机或责任。区分可理解、可同情与正当；不要用创伤、善意或后来的惩罚自动抵销人物已经造成的后果，也不要把所有美德解释成病灶。若作品选择宽恕、修复或拒绝修复，必须让人物承担相应的主动行为与损失。

### 伤害/反应比例

伤害的严重度、亲近度、可逆性和人物的既有经验共同决定反应的强度、形态与时机；沉默或延迟反应也要有可追踪的载体和下一压力。不要用夸张惨烈掩盖因果，不要把痛苦当装饰、奖赏或唯一的深度证明，也不要让重大伤害只换来一行无差别的悲伤。

### 正向艺术验收

“没有新增错误”不等于通过。候选文本至少要保留或增强一项目标读者能感到的正向效果：人物特有的欲望与选择、清晰的紧张/好奇/喜悦、关系或谜题的可见推进、具体而有辨识度的声音与意象，或有准备的惊喜。与此同时，不得损失既有的因果、知识权限、承诺、人物尊严、声音和后续选项；两轴冲突时退回上游决定，不用漂亮句子掩盖损失。

## 使用与停止

- 写作或设计前先判断当前单元真正承载链条中的哪些环节；重要场景或章节用一两句话对齐完整链条，只做句段编辑、低选择移动或过渡概述时，只需确认它服务哪一项承诺和哪一种人物体验，不强造一次重大选择。
- 修改或评价时沿链条找断点，再从断点向下检查；改动任一上游项后，重新检查其后的后果与文本实现。
- 若本应承载重要选择或状态变化的单元尚未建立压力、人物责任或后果，停止润色并路由到结构、人物、类型或修订技能；低选择过渡只要承担清楚的定位、承接或节奏功能即可概述或压缩。若表达层修复需要新增场景、改变选择或改变言语行为，交回相应创作提供方。
